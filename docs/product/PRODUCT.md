# Ivy · Product Requirements

更新：2026-09-23。汇总从开场至香水铺的修订、后四站新玩法与存档命名要求。本文记录目标需求；接入和用户验收另行确认。

## 产品与资料职责

Ivy 是送给一个人的私人横屏 iPhone 回忆解谜游戏。院子和大厅组成小屋，大厅进入香港旅程，十三件纪念物收齐后回大厅领取预先确定的礼物。无账号、排行榜、随机奖品或死亡惩罚。

本 PRD 描述目标体验、需求范围和交付顺序。[IVY-GUIDE.md](../gameplay/IVY-GUIDE.md) 维护玩法基线与设计原则；[UI-RULES.md](../ui/UI-RULES.md) 维护交互和美术约束；[DEVELOPMENT.md](../engineering/DEVELOPMENT.md) 维护状态和兼容边界；[9 月 21 日整改](2026-09-21-playthrough-revision.md)记录前段执行项，[9 月 23 日设计稿](../gameplay/2026-09-23-later-eggs-tool-design.md)定义后四站玩法。

用户最新要求优先。本文区分明确需求、建议方案和当前实现；写入 PRD 不等于方案已获批准或已交付。

## 核心体验

核心循环升级为：**发现提示 → 理解规则 → 操作并验证推断 → 根据结果搜寻 → 改变世界 → 留下回忆**。玩家应能解释为什么动作有效，而不只是把画面点一遍。规则由场景证据教会，推理可涉及空间、数学、物理、顺序、集合与语言。每个主谜题至少有一个需要理解关系的决策；纯观察和轻互动负责节奏与情感。

借鉴锈湖的固定视角、物件因果、跨视角线索和解开后的空间变化；保留 Ivy 温暖、私人、哑光绘本的世界，不引入恐怖、猎奇或虚构共同经历。

## 系统需求

| 需求 | 目标行为 |
| --- | --- |
| 锁板与键盘 | 键盘、输入、Enter 和反馈完整落在锁板内；优先紧凑方阵，矮屏采用横向组合；保留触控尺寸 |
| 控件美术 | 复用已批准的单一常态键帽、短输入槽和 ✓ 确认图标；按下／禁用由现有控件样式表达，不另做键帽素材 |
| 提交稳定性 | Enter 后输入区、键盘及面板锚点不移动；反馈预留空间，错误保留输入 |
| Dialog 与导航 | 普通场景 Dialog 不隐藏有效左右箭头；近景不暴露底层导航 |
| 动效节奏 | 同地点视角直接切换；跨地点短黑场切入切出；Dialog 快速出现 |
| Notes | 空白页文案为 `No clues recorded yet.`；只记录发现的证据，固定入口、阅读位置和返回上下文 |
| 工具身份 | 点击或开始拖拽时显示完整英文名称；取消常驻名称标签，包括香料，不推荐答案 |
| 收藏保密 | 香水未发现 icon 使用无具体物体轮廓的封存视觉；已发现缩略图仅用东京 Gaiac 10，仍保留三瓶制作 |

## 物件、状态和存档

目标收藏 ID 与顺序：`letter, vuori, plane, keycard, city, rose, gelato, noodle, perfume, cinema, dictionary, ferris, taxi`。`perfume` 与 `dictionary` 分别取代旧 `supermarket` 与 `sunset`；新代码读取旧收藏值并迁移完成状态，不能清空玩家进度。本轮已迁移 `perfume` 房间、导航边和收藏枚举；`dictionary` 已接入旧 ID 与完成事实迁移，尚未构建或设备验收。

保留玩家已有收藏、通行权限、工具持有/消耗与线索。新状态向后兼容；已完成关卡不强制重玩。随机散片位置、原料位置若随机、灯管排列生成一次并持久保存，不随重开刷新。打开、发现、拿取、使用、收藏分别记录。拼合收藏本体的关卡完成即解锁并进入 Element；重看不重复发奖。review 模式不得写入正常存档。

## 美术与可访问性

采用 Yard 画风的哑光手绘素材；可见文字原则上为英文，Dictionary 歌词纸卡也按 2026-09-24 最新要求使用英文。Notes、锁板交互文字与玩家在 Dictionary 的真实笔迹按 UI 规则处理，其余显示文字制成素材，语义标签独立保留。键帽、拼图壳、双光照房间、雨景和收藏 icon 先做实际构图设计稿。香料建立逐项素材映射和表面锚点。

拖拽和连续滑动谜题提供等价无障碍操作，不让普通点击绕过核心推理。Reduce Motion 保留证据和状态，取消不必要移动、雨粒和闪动。任何谜题不依赖短暂反应窗口或只用颜色表达证据。

## 交付顺序

1. 系统稳定性：锁板、Enter、Dialog 导航、快速切景、工具身份和 Notes。
2. 现有场景：Vuori、酒店、灯管切景、菜单单一入口、香水题字和 icon。
3. 玩法深化：按已确认的 Gelato 雨水流路方案继续细化规则与线索；完成 Big Top、香水的规则确认，再制作素材、接入状态。
4. 后续四站：按已确认的[道具与玩法设计](../gameplay/2026-09-23-later-eggs-tool-design.md)接入 Cinema、Dictionary、Ferris、Taxi，完成旧收藏迁移与终局；素材已交付，运行和用户验收未完成。

完成状态分开记录：需求已整理、设计已批准、素材已交付、实现已接入、用户已验收。后四站设计和分层素材已交付，游戏仍保留旧占位；本轮防穷举设计已批准并接入源码，设备游玩待验收。日常测试由用户负责；本轮文档整理不运行测试、构建、设备或截图。
