# Ivy · 游戏设计总纲

更新于 2026-09-23。本文沉淀当前设计共识；具体 UI 尺寸、控件和反馈规则由 [UI-RULES.md](../ui/UI-RULES.md) 维护，工程约束由 [DEVELOPMENT.md](../engineering/DEVELOPMENT.md) 维护。

## 基线与资料优先级

当前设计目标覆盖 **Yard → Hall → Plane → Corridor → Bedroom → Gelato → Big Top → Le Labo → Cinema → Dictionary → Ferris → Taxi → Hall 终局**。此前“到 Gelato 为止已测验”的结论仍说明旧版本的体验基线；9 月 21 日修订了此前关卡，9 月 23 日明确了后四站玩法与防低成本穷举规则。设计目标不等于代码已接入或用户已验收。

这是设计基线，不代表所有机型、存档迁移、无障碍或运行版本已验收。目标需求见 [当前 PRD](../product/PRODUCT.md)，前段整改见 [9 月 21 日清单](../product/2026-09-21-playthrough-revision.md)，后四站的具体谜题与素材状态见 [9 月 23 日设计稿](2026-09-23-later-eggs-tool-design.md)。

冲突时按以下顺序处理：

1. 用户最新的明确要求与批准的具体设计。
2. 本总纲、UI-RULES 和 DEVELOPMENT，各自负责玩法、界面、工程。
3. 对应场景的已批准素材和专项说明，保留其局部例外。
4. PRODUCT 汇总目标需求和交付范围，具体规则回到上述权威出处；美术 README 记录素材来源与交付，不能覆盖当前玩法。

代码用于确认“目前如何实现”，不能把偶然实现升级成用户偏好。旧文档中的 Approved 标记不凌驾于后来的用户修订。更改规则时更新它的权威出处，避免继续在各文件尾部堆叠互相矛盾的补丁。

## 游戏是什么

Ivy 是送给一个人的私人横屏 iPhone 回忆解谜游戏。院子和大厅组成小屋，大厅通道通向 Wonderland 香港；玩家沿旅程收集十三件纪念物，再回到大厅领取预先确定的礼物。没有账号、公开排行榜或随机抽奖机制。

体验围绕“认出共同记忆、观察物件、亲手完成动作”。借鉴锈湖式的物件与库存推理、The Room 式的近距离观察，但空间、控件、语气和纪念物属于 Ivy 自己。不要为凑谜题编造真实共同经历；场景布置和游戏化演绎应与用户提供的私人事实区分。

## 风格与视觉

当前方向以 **Yard 场景画风**为基准，是带像素绘本气质的哑光手绘世界：清晰深色轮廓、成组色块、克制的阶梯状笔触、纸张与布料质感、深青绿阴影和局部暖琥珀光。具体参考图、不同天气与近景的处理以及出图核对见 [图片生成规则](../art/IMAGE-GENERATION-RULES.md)。不因“像素”而将高分辨率手绘图重新降为低清像素图。

香港旧酒店与植物机械的气氛仍成立：旧木、黄铜、暖纸、玻璃、织物和克制的常春藤。世界亲密、安静、略带神秘，保持生活感；不引入恐怖废墟、强霓虹或通用网页卡片视觉。Jellycat 的笑脸和红玫瑰是用户指定物件，不能用旧文档的“禁止可爱”否决它。

同一地点的多视角必须是同一个空间：物件、材质、光线和出入口彼此对应。Gelato 的主景、长椅和服务侧景都属于同一个户外摊位，不能一转头变成室内店铺。物件近景是完整空间，不把矩形场景插图贴进另一张面板。

Rose 保留三朵红玫瑰、笑脸牛皮纸包装、棕色手臂和绿色花茎；侧躺姿态与枕头的相对位置以 `art/room/rose-bed/placement-reference.png` 为准；使用独立侧躺素材 `rose-lying`，花头朝左、笑脸包装与花茎横向朝右，不再旋转压扁竖立素材。Rose 与窗户拼图采用用户已批准的背景虚化，主体保持清楚。这是局部景深处理，不是给全游戏加模糊滤镜。

所有玩家可见文字原则上为英文，包括 Gelato 和私人回忆；Dictionary 的实体歌词纸卡保留用户指定中文“在爱情字典里找不到永远”，是局部例外。Kiddos 用于系统文字，Juniper 用于物件题字；批准机票上的 Georgia Italic 路线文字是具体例外。除 Notes、lock pad 交互字和 Dictionary 玩家手写笔迹外，其余可见文字设计成素材；保留独立交互与无障碍语义。具体制作边界以 UI-RULES 的「Text artwork and Notes」为准。

## 玩法语法

### 后续设计原则 · 2026-09-21

主要谜题采用“提示 → 理解规则 → 推理或实验 → 有依据地搜寻 → 主动操作 → 世界变化”。搜寻可以先提供证据，也可以是推导后的行动；不要机械限定顺序。每个主谜题至少有一个理解关系的决策，不能只把物件藏得更深、增加热点或延长密码。

### 防穷举完成规则 · 2026-09-23

**主谜题不能靠不读线索、依次点击所有热点／选项或利用逐步正确反馈，在普通游玩时间内完成。** 制作前要从“完全不看证据的玩家”视角写出最短穷举路径；若这条路径只需扫完少量选项、逐位试出答案，或遍历柜格就能通关，设计不合格。仅增加按钮、柜格、密码长度或点击惩罚，不算修复。

- 线索必须支持一个可说明的关系判断；最终操作要运用该关系，而非只检查玩家是否点开过线索。错误可以观察和修正，但不逐项报告“这一步对了”，以免把反馈变成答案筛选器。
- 实物实验可以给出符合世界规则的连续结果，例如水实际流向哪里；不能用二元对错提示替代推理。完整答案须在有意义的整次操作后判定。允许回退，不设置点击次数上限、计时惩罚或耗材惩罚来阻挡穷举。
- 短暂的拿取、开盒、试吃和最终装盒可以作为已解主谜题的行动或情感间奏；不能把一组少量可逐个试完的动作包装成独立主谜题。新谜题和修改中的谜题均需通过上述盲玩审查。
- 有限状态的谜题理论上都可穷举；本规则针对**低成本盲扫**和会泄露正确前缀的反馈，不要求用无限选项或不可逆失败制造数学上的不可穷举。当前审计和待审核重设计见 [防穷举玩法审计](2026-09-23-anti-greedy-puzzles.md)。

- 规则必须在游戏内通过实物示范和可记录证据学会；数学、物理、空间、集合、语言与路线规划均可使用，不要求外部专业知识。
- 为每关明确规则示范、线索位置、完整解法或合法解集合、主动操作、错误修正、世界变化、收藏/离开条件及旧进度映射。要求唯一解的谜题须给出完整推导；多解谜题接受所有符合规则的解。
- 相邻主要关卡避免重复同一认知过程。每关以一条主规则为中心，短观察与回忆仍可作为间奏，不给每件收藏强塞复杂机械题。
- 错误应让玩家修正假设，保留合法进度与工具；不能通过逐件“正确”提示取代全局推理。无障碍方式保留同一推理要求。
- 搜寻位置应由物件形态、空间关系或证据支持；真实物件操作改变可见状态。保持私人事实与游戏化装置的区分。
- 2026-09-23 已确认的 Vuori 修改：去掉吊牌答案提示，以布面绣字连线；Gelato 以连续转轴水路揭示标记，再用菜单约束定位口味；Le Labo 礼盒使用产品数字 X、XXII、XXX。具体接入状态以本轮交付记录为准，设备游玩验收仍由用户完成。
- Gelato 服务侧景已接入现有 `gelato-gutter-empty` 全景，和水路近景共用 `GelatoGutterArtwork` 的转轴、水线及浮签状态；水路、刻纹盘、柜台和工具盒热点按该图重新定位。未生成新素材，未运行构建或设备验收。
- Cinema、Dictionary、Ferris、Taxi 的玩法方向与具体道具已在 9 月 23 日设计稿中明确，仍未接入或由用户游玩验收。Dictionary 取代 Sunset 的关卡、收藏 ID 与画面；接入时把旧 `sunset` 存档进度迁到 `dictionary`，不要求已完成玩家重玩。

### 已实现的物件交互基线

典型过程是：**观察 → 点实物近看 → 发现或拿取 → 自己选择工具 → 操作物件／理解线索 → 世界状态改变 → 收取纪念物**。这是设计语言，不要求每个谜题机械地走完全部步骤。

- 空间必须解释入口：点装饰盒进入盒子谜题，点书打开书，点舱门登机；不能点整张桌子误入一个小物件。
- 同地点左右箭头切换视角，门、台阶等实物承担跨地点移动。不存在的方向隐藏按钮；返回保留原视角、输入和操作进度。
- 打开容器、拿走其中物件、消耗物件是三个独立事实。开盒不自动拿完，离开再进也不补货。
- 拾取任意工具（包括花瓣）后自动切到 Tools；不自动选中或使用工具。玩家仍可自由切换 Memories / Tools。依赖工具的物件在缺少工具时只显示 Dialog，不进入空交互页；已完成物件与独立阅读线索不受此限制。
- 消耗后的工具和放好的花瓣退出 Tools，空占位也移除，其他工具补位。Memories 的十三收藏位置保持稳定，两种栏位规则不同。
- 错误选择允许修正，保留输入或排列，不惩罚性丢失工具。反馈可以沉默或是简短的世界内反应，不能教玩家下一步怎么做。
- Notes 是独立可翻页的笔记本，记录已发现的证据。入口固定在 Tools 首位，不随其他工具滚动；每次打开恢复上次阅读位置，新增线索不能导致位置错页。原物件上的图案在笔记里仍是同一图案和顺序，不能转译成答案文字或攻略。
- 谜题各有合适动作：拼字、连线、擦拭、交换、拖放、试吃。不要把所有关卡都变成输入密码或多余工具检查。

| 地点 | 最新设计规则 |
| --- | --- |
| Yard | 信箱藤叶下的日期线索，数字盘输入 817，获得 letter。大门拼出 coveredinyou 后只开门并返回院子，玩家再点击已打开的大门进入大厅，大门本身不奖励收藏。花盆近景中显露的钥匙需要另外点击收取。锁板采用稳定的键帽、输入槽和 Enter 布局，提交不移动键盘。 |
| Hall | 主动用钥匙打开抽屉，再拿橡皮。Vuori 在布面九个打乱的绣字之间一次连续滑动，松手判定完整 VUORI 路径；正确则解锁，错误或不足五字母则立即清空。无 Clear／Enter，不显示起点、方向或预画答案，短点和多次抬手不能累积成答案。 |
| Plane | 场景 2 的旅行书有独立近景，书中 ticket 手动拿入 Tools；场景 1 舱门承担登机入口。橡皮擦除石墨揭示符号顺序，Notes 保留图案。十个无名称城市点中先选杭州再选香港；持票、路线和线索条件满足后才能出发。出发消耗 ticket 工具并获得 plane 纪念物。云南明信片是独立实物回忆。 |
| Corridor | 找到并拿取布，主动选择它擦去镜面水汽，结合机票符号顺序读取本局生成且持久保存的房号；四位锁正确后掉出房卡。点击收卡飞入收藏后自动开门，玩家再点击门进入。房号不是固定 1608。 |
| Bedroom / HK Hotel | 装饰盒谜题仍回答 as a whole；打开后分别拿花瓣和 Gelato 代币。夜景为九块正方形拼图，采用已批准的正上方俯视桌面、大尺寸深青色木托盘；散片受约束地随机分配到固定堆叠位置，带旋转、遮挡与接触阴影，可移动、交换、取回，首局布局持久保存，放错保留且无逐片正确反馈，完整复原才解锁 city 并进入 Element。灯灭/灯亮是同一房间的两个光照状态，灯亮照出纸垫花瓣；开关可反复切换，已发现/拿取事实不重生。Rose 找齐三片花瓣后由 Tools 拖入花头，完成即解锁 rose 并进入 Element。 |
| Gelato | 同一户外摊位三个视角，斜雨与棚沿水流作用于刻纹小盘；棚内菜单保持干燥。三处转轴连续调整水流方向，错位落入溢流口，仅整条水路进入刻纹盘才揭示浮签。浮签的罐位标记与果实/花香证据共同定位 White Loquat & Jasmine，玩家主动用勺试吃，错误可改且不消耗勺。 |

Rose 三片花瓣的最新位置：床中央偏左的毯子褶皱、台灯触发后桌面中央纸垫、装饰盒内部。第一片已经从枕头下移走：点击毯子褶皱进入独立近景，向上拨开折边（也可点击），再点击花瓣拿取；近景保留揭开状态，拿取后不再出现。其余花瓣发现后仍需拿取；使用后的槽位移除。

## Big Top 与 Le Labo · 截至香水铺的最新设计

以下是本轮用户确认后的设计规则；它们替换同场景旧的“直接点选/二十一种全收集”描述。实现完成前不称为用户验收。素材与旧实现记录仍见 Big Top 与 Le Labo 专项，但与本节冲突时以本节为准。

- Gelato 出口的六根彩色玻璃灯管随机打乱并持久保存，排除正序和倒序；目标顺序是 B → I → G → T → O → P。玩家选满六根才整串判定，不反馈正确前缀；完成时先保存事实，再归位，最后切入 Big Top。
- Big Top 场景 1 负责餐桌与点单：从场景 2 取菜单、放到点餐夹板后直接打开；之后点已放菜单直接阅读。四页二十项菜单用铅笔勾选 Half Roast Goose、Steamed Rice、Rice Noodles、Lemon Tea、Ovaltine，以实体铜铃提交，错单保留勾选。正确上菜后餐桌出现五样餐食，第一次点击进入 Element 并保存 noodle。场景 2 服务柜有两排四列八格门；桌面描图纸倒置，旋转半周并沿导轨平移，让两孔套钉、窗孔指向下排第三格，才能打开柜格另取菜单。柜门盲点不能直接取得菜单。
- 餐馆出口通往独立斜街道，店门进入 Le Labo；街道不与店内视角共用左右箭头。完成香水后从街道上坡前往影院。
- Le Labo 四个室内视角按材质容器分布原料：木材/树脂、植物、香料抽屉、实验柜。原料总数目标为 20 种：从现有 21 种中移除一个非必需干扰项，同时保留旧 ID 兼容。玩家先阅读配方材料特征，再根据形态、储存方式和跨视角证据寻找需要的原料，无需先清空所有房间。每瓶仍接受一个核心与两个不同辅助，材料可复用，错误组合保留。
- 三瓶完整名称为 Gaiac 10、Bergamote 22、Mousse de Chene 30。工作台三个瓶座接受任意原料，主动按灌装器才判定；成功产生可拿取成品。纸盒三格允许错放、交换和拿回，完整正确顺序为 Gaiac 10 → Bergamote 22 → Mousse de Chene 30。盒盖顺序证据使用对应产品数字的罗马数字 X、XXII、XXX，不表示槽号；完整排列自动保存 `perfume` 并进入 Element，无额外领取点击。旧 `supermarket` 收藏与房间值均解码为 `perfume`；存档的视角键也迁移。
- 配方册已读页面和盒盖顺序证据原样进入 Notes；工具拾取切到 Tools 但不自动选中；工具/香料名称只在点击或开始拖拽时短显，取消常驻标签。既有工具栏滚动位置与十三个收藏槽保留；旧收藏 ID 和完成存档按下方迁移规则兼容。

## 收藏、回忆与节奏

香水铺后的当前设计按 [后四站道具与操作设计稿](2026-09-23-later-eggs-tool-design.md) 执行；分层素材已制作，游戏接入与用户验收另记。旧 9 月 21 日整改中的 Sunset 视差、两票摩天轮、Cinema 填词和 Taxi 反义词均不再是目标玩法。

| 地点 | 证据 → 主动操作 → 结果 |
| --- | --- |
| Cinema | 票根半心缺口决定胶片正反；从胶片盒单独取出透明胶片，放入放映机并平移，让两层半心与座位轮廓重合，随后选 C3、C4。错位可调整，完成保存 `cinema`，回访保留投影。 |
| Dictionary | 在旧书摊阅读歌词纸卡与缺词的字典，从笔架单独拿钢笔；选笔后在空白词条亲手写英文 `FOREVER`。判定实际笔迹，失败可修改，成功保留字迹、笔归架并获得 `dictionary`；歌词卡的中文是此场景唯一已批准的语言例外。 |
| Ferris | 维修台示范重量与力臂，玩家从维修箱取出 `III` 配重，放在右侧第 2 格，与左侧第 3 格的 `II` 平衡；转动手柄后轮体运行、车厢开启。错放可取回，保留 `ferris`。 |
| Taxi | 车窗地标、路线卡与单行路线盘共同限定方向、必经 E 和关闭的 F 隧道；玩家绘制 `A→B→E→D→G`，错线可撤回。抵达后景色变化，收据承接回忆，保存 `taxi`，车门可回大厅。 |

后四站继续执行主谜题防低成本穷举、工具主动选择、证据入 Notes、可逆错误与旧进度兼容。

十三个目标收藏 ID 和顺序：

`letter, vuori, plane, keycard, city, rose, gelato, noodle, perfume, cinema, dictionary, ferris, taxi`

工具、花瓣、可选私人回忆不新增收藏位。`perfume` 取代旧 `supermarket` ID，`dictionary` 取代旧 `sunset` ID；接入时需读取旧值并持久迁移已完成进度，不要求玩家重玩。房间与收藏枚举均已改为 `perfume`；历史素材文件名无需随存档 ID 改动。集齐后回大厅领取最终礼物。

实物领取类纪念物首次取得时飞入真实库存槽位；拼合成品即纪念物的关卡（如香港拼图与 Rose）完成即保存并直接进入 Element，不插入飞行动画或第二次领取。再次点击收藏统一为 Element：当前场景虚化、左侧清晰物件／图片及闪光藤蔓、右侧英文回忆；进入与退出有淡入淡出及轻微位移，减少动态效果时仅短淡变；不重复发奖，也不先播旧透明特效再接第二段展示。云南明信片与 Causeway Bay 采用同一布局；普通环境点触仍为短 Dialog。此修订替换 letter／Vuori 仅透明特效的旧例外。根级 Back 与 footer 不虚化；关闭返回原视角或原近景。

动效解释状态变化：开合、归位、收取。尽量让玩家继续探索，不增加无意义等待；Reduce Motion 使用淡入淡出等替代，无障碍提供等效操作。Cinema、Dictionary、Ferris、Taxi 的设计已明确，运行接入与用户验收仍待完成；本轮 Gelato、灯管与 Big Top 的防穷举设计已批准，设备游玩验收未完成。
