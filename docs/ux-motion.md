# Ivy — 动效与过渡（UX）

Date: 2026-09-17  
Product: 原生 SwiftUI，iPhone 15 Pro（3x），横屏礼物  
Depends on: [game-design.md](game-design.md)（玩法、五景、九蛋、触感表）。本文只写 **怎么动**，不改支柱。  
Audience: 实现与评审  
Status: 大门改为 **拼字关新画面**（点选拼接，对上自动进厅）。五次惊喜仍在；第 5.4 不再用系统键盘。

---

## 0. 一句话

**惊喜铺在「认出」的五下，不铺在每一帧。** 前院可以有一层很慢的像素呼吸（藤、云），它不是惊喜，是屋子活着。触感是第一声，图层过渡是第二声，换房底图永远切帧。

不是落地页，不是 H5 抽卡，不是 `NavigationStack` 工具 App。壳是卡带：夜色信箱 + 320×160 画布。系统 `.sheet` 会露出抓手和父页，破掉这层。系统键盘会把大门做成填表，大门关不用。

---

## 1. 设计读法

横屏 16-bit 点选礼物。一人玩，可能躺着、可能切去微信。语言：安静 SNES 小屋。

| 旋钮 | 值 | 理由 |
|------|----|------|
| 构图变化 | 4 | 固定机位，不是电影机位 |
| 动效强度 | 3–4 | 8–15 分钟礼物；过场会吃掉点景时间。前院气氛循环强度 2：慢、步进、可关 |
| 视觉密度 | 3 | HUD 只有底栏九槽；天空填空算景里的字，不是 HUD |

80% 时间在某一景里点。动效只服务三个动词：**近看、收下、屋子记住**。风和云服务「屋子记住」的气氛，不服务新动词。大门拼字是「点」的变体，不是第四个动词：板按下、行变长、对上切厅。

减动效（`@Environment(\.accessibilityReduceMotion)`）时：去掉位移和缩放，保留状态变化（槽变色、切灯、信出现、藤档位、拼接行变长），opacity ≤ 150ms。**藤停在该档第 0 帧，云停在能读到填空的位置。字盘打开时直接在位，不要洗牌动画。**

## 2. 两层运动，不要混

| 层 | 什么 | 怎么动 |
|----|------|--------|
| 像素世界 | 房间底图、灯、物件补丁 | **切帧**。`Image` 换名时 `transaction { $0.animation = nil }`，禁止默认 crossfade |
| 像素气氛（仅前院） | 藤摇、云、天空字 | **步进循环**。2–4 帧或 1px 平移；不要对底图做 ease。**拼字关是另一张图，前院气氛不跟进那张画面** |
| 系统层 | 特写、对话箱、栏、信箱/Vuori 短输入、信 | `withAnimation`。不要用 `.animation` 绑在画布上（会把换房也做成插值） |
| 拼字关 | 底图、字盘、拼接行 | **切帧**。点板 = 按下 1px + 行末多一个字形。禁止键盘弹起插值 |

房间图只留 Catalog **@3x**。逻辑画布仍是 320×160，最近邻放大。旧像素素材（intro / obj / ui）可以只有 1x。拼字关底图与字盘 glyph 按同一套最近邻。

## 3. 壳与导航（对话结构）

深度永远两层：**屋子** → **近看或拼字或短输入** → 回屋子。换房是点门热点，不是 push。点未开的大门是切到拼字画面，算换一张「景」，仍在这两层里（不是第三层导航）。

```
ZStack
  Color("Night")                 // 信箱，ignoresSafeArea
  若未开拼字关:
    PixelCanvas                  // 安全区内居中 320×160
      底图 yard（尽量无藤、无云）
      天空字（静止）
      云 overlay（步进平移，盖住部分字）
      左藤 overlay × 档 × 摇帧
      右藤 overlay × 档 × 摇帧
    热点（透明，≥ 44pt）
    特写层 / 信箱短输入压暗层
  若拼字关打开:
    LyricLockCanvas              // 同一 320×160 槽，换图，不是 sheet
      拼字底图
      拼接行（只读字形）
      4×4 字盘
      离开 / 退格 / Reset
safeAreaInset(edge: .bottom)     // 物品栏；拼字关时隐藏
```

| 场景 | 容器 | 不要用 |
|------|------|--------|
| 房间之间 | 同一 `ZStack` 换 `Image` 名 | `NavigationStack`、`TabView`、走路条 |
| 大门拼字 | 同一画布槽换 `LyricLockCanvas` | `.sheet`、`.fullScreenCover`、系统键盘、`TextField` |
| 特写、信箱/Vuori、信 | 画布上的层 | `.sheet`（抓手）、玩法中的 `.fullScreenCover` |
| 竖握转屏提示 | 可 `fullScreenCover`：此时还没有屋子 | 把房间侧着放 |
| 提示 / 收下成功 | 对话箱、栏、触感 | `.alert`（非破坏性信息） |
| 主界面图标 | 像素图（`ui-skip`、槽、字盘板） | SF Symbols 做主界面 |

Skip、槽、门、字盘板、退格、Reset、离开、信箱确认：**≥ 44pt**。`Night` 可以顶到屏幕边；栏、Skip、拼字控件、信箱确认必须在安全区。横握时 Island / Home 不抢点。

切去微信再回来：停在原景 + 原特写/拼字/短输入；拼字行与字盘顺序都还在；信箱键盘可丢，数字保留。不要重播片头。不要重洗未关的字盘。

## 4. 过渡词汇

全 App 只准这些。新动效先问：它服务近看、收下，还是屋子记住？说不清就不要。

| 意图 | SwiftUI | 时长 |
|------|---------|------|
| 特写从物件长出来 | `matchedGeometryEffect` + `.smooth` | 280–350ms |
| 特写关掉 | 非对称：缩小回热点 + opacity | 200ms |
| 对话箱进出 | `.move(edge: .bottom).combined(with: .opacity)` | 200ms |
| 栏亮一格 | `.snappy` + `scaleEffect` 1 → 1.12 → 1 | 180ms |
| 厅灯 | 先压黑再切 `hall` / `hall-dark` | 160–220ms |
| 大门对上 | 短黑（opacity）再切厅 | ≤ 180ms |
| 点门进拼字关 | 与走门相同：切前 2pt，然后切到拼字底图 | ~80–100ms |
| 点字盘板 | 1px 按下（`PixelPressStyle`），抬起；拼接行末 **立刻** 多一个字形 | 0ms 切帧 |
| 拼错（非前缀） | 拼接行末字 offset 2pt 抖一下 | ≤ 120ms |
| 退格 | 末字切掉（不要 reverse typewriter） | 0ms |
| Reset | 整行切空（不要逐字收回） | 0ms |
| 走门方向感 | 切前 `offset` 2pt，切完回 0，`.linear` | ~80–100ms |
| 前院藤摇 | 3 帧 ping-pong，每帧 400–500ms，位移 ≤ 2 游戏像素 | 循环 |
| 前院云 | 云层 overlay 每次跳 1 游戏像素，约 250ms 一步，横向循环 | 循环 |
| 前院收下长藤 | 当前档 overlay **一帧切上** 下一档，不要 dissolve | 0ms 切帧 + `.medium` 在槽上 |
| 信展开 | `.move(edge: .bottom)` + opacity | 360–400ms，**全游戏最长** |
| 减动效 | 只留 opacity | ≤ 150ms |

缓动：像素帧 **linear / stepped**。系统层 `.smooth` / `.snappy`。画布上禁止 `.bouncy`、模糊 dissolve、弹簧弹整张图。

触发用 `withAnimation { }` 包住用户点按导致的状态变化。不要用 `.animation(_:value:)` 监听房间名。

## 5. 五次惊喜

其余点都是轻的：1px 边、`.light`、废话对话箱。预算花在这五下。素材用色块占位时，过渡也要按这套写，换 PNG 只换 `Image` 名。

### 5.1 近看：这个东西变大了

点热区 → 同一件东西长成特写左图。物体恒常，比飞进栏更像锈湖。

- 左右分栏，图 : 文 ≈ φ。对话箱用 `ui-dialogue`。返回在文栏下沿 44pt。
- **下滑只关特写**（阈值约 80pt），不关 App、不换房。
- 夜色信箱始终在。
- 占位：热点矩形和特写色块共用一个 `@Namespace` id。以后换特写图，id 不变。
- 废话点没有特写，只有对话箱一句（约 160ms）。

### 5.2 收下：栏认了，不是物体飞走

飞进栏是抽卡 H5，**不要** `matchedGeometry` 到槽。

1. 特写还在，停约 80ms（让他看完考察）。
2. 特写缩小回热点（200ms）。
3. 对应槽 `.snappy` 放大一拍并染色，同时 `.medium`。
4. 若已有藤 overlay：前院走「左右对称切档」（见 5.6）；其它景仍可用 `opacity` 从 `n/9` 到 `(n+1)/9`，线性约 200ms；没有就跳过。
5. 若已有物件补丁：补丁 `opacity 0→1` **一帧切上**，不要渐变物体本身。
6. 立刻可再点。不要锁操作 1 秒。

点已收槽：再打开考察，走特写进出，**不再爬藤、不再播收下**。

### 5.3 关灯：世界突然只剩一块屏

现成 `hall` / `hall-dark` 就能做的最大魔术。

1. `withAnimation(.smooth(duration: 0.12))` 把画布压到黑。
2. 切图（无动画）。禁止两张厅图 crossfade（对不齐会鬼影）。
3. 暗厅亮回来。口袋亮屏已经画在 `hall-dark` 里，**第一次关灯不要再叠呼吸灯**。
4. `.medium` 一次。厨房、楼梯、卧室不跟着闪。

2 分钟仍关灯且未收 `vuori`：口袋 1px 脉动，每局最多一次。不要和第一次关灯抢。

已收 `vuori` 后暗厅口袋不应再亮。底图仍画着灯时：用暗色补丁盖住，或补一张无亮屏的 `hall-dark`。没补丁前，收下后仍切暗厅（已知缺口）。

### 5.4 大门：屋子认他（拼字关）

点未开的大门：**切到新画面**，不是弹出键盘。这张画面是门的内侧——夜色、拼接行、字盘。栏收起。前院云和藤不跟过来。

#### 进关

1. `.light`（与走门同一档）
2. 朝门 2pt 再回正（减动效则跳过）
3. 瞬切拼字底图（`transaction { $0.animation = nil }`）
4. 字盘 16 块已经洗好、在位。不要洗牌飞入、不要逐块 stagger

#### 点板

每块板是像素石板（奶油字 / 夜色底，语言对齐 `ui-enter`），按下 1px 亮边。`PixelPressStyle`。热区在设备上 ≥ 44pt（约 16–18 游戏像素，视放大倍数而定）。

点一下：

1. 该字形接到拼接行末尾（系统拼接，他不打字）
2. 若是答案前缀：`.light`，行只变长，不闪对号
3. 若不是前缀：行仍接上这个字，末字抖 2pt + `.warning`，口语提示；不自动删
4. 若恰好 `coveredinyou817`：走下面「对上」
5. 行已 20 字：不再接，`.warning`

拼接行是只读雕刻，同一套像素字（与天空填空同源）。**不要光标闪、不要 iOS 选区、不要占位符写成答案。** 不要画 15 个空槽。

退格：贴在拼接行右侧 44pt。切掉末字。无触感或极轻 `.soft`。不减失败次数。

**Reset：** 退格外侧再一块像素板（文案 `RESET`，语言对齐 `ui-enter`）。清空整行，**留在拼字画面**。字盘不重洗、不位移。`.light` 一次。行已空则无操作。不要做成二次确认、不要 Alert「是否清空」。

离开：左端 44pt。切回前院（普通切景，无黑场）。字保留。字盘下次打开再洗。Reset 与离开分开：一个清字，一个出门。不要挨在一起。

下滑不关拼字关。

#### 对上

对上歌词（拼接行 == `coveredinyou817`）：

1. `.success`
2. 画面压黑 ≤180ms
3. 瞬切 `hall`
4. `ivy` 槽走「收下」第 3 步；前院左右藤档在切走前或回来时已是 +1

不要再播一遍独立进门过场。不要等他按确认。对过之后进出大厅不再加黑场，只走普通切景（可保留 2pt 方向感）。

错（非前缀）：框/末字抖 2pt + `.warning`，字留着。第三次只换口语提示，不闪红屏、不清进度、不踢回前院。不把空格填成 `covered in you`，不在提示里写 `817`，不点亮正确板。

#### 构图（320×160）

| 带 | 游戏像素 | 说明 |
|----|----------|------|
| 底图 | `lock-bg` 320×160 | 门内侧橡木 + 铁锁板；**不含**字母 |
| BACK | x 6, y 8, 40×14 `ui-back` | 回前院；字保留 |
| 拼接槽 | x 50, y 12, 164×14 | 只读雕刻；字形 `lock-mark-*` 10×14，间距 1，从 x 52 起 |
| DEL | x 220, y 8, 28×14 `ui-del` | 退格 |
| RESET | x 250, y 8, 48×14 `ui-reset` | 清整行；与 BACK 分两侧 |
| 字盘原点 | x 106, y 40 | 4×4；单块 `lock-tile-*` 24×24，缝 4（格距 28） |
| 口语提示 | y 150 一带，可空 | 第三次才加强；不是 Alert |

#### 字盘（运动规格）

| 项 | 做 | 不做 |
|----|----|------|
| 16 块 4×4 | 打开时 `shuffle` 一次 | 每点一次重洗 |
| 打开期间 | 位置冻结 | 切后台再洗 |
| 减动效 | 板直接在最终位置 | 任何位移/stagger |
| 诱饵 `9` `a` `s` | 外观与真字完全一样 | 灰色/缩小诱饵 |

#### 信箱 / Vuori（仍用键盘，仅这两处）

| 关卡 | Keyboard | 其它 |
|------|----------|------|
| `vuori` | `.asciiCapable` | `autocorrectionDisabled()`，`textInputAutocapitalization(.never)`，`submitLabel(.done)` |
| `sep29` | `.numberPad` | 规范化 929 / 9.29 / 0929 |

输入框与确认同一行，`safeAreaInset` 贴键盘上沿。点空白不收键盘。取消在板左端 44pt。进短输入时栏收起、当前景压暗。**大门禁止走这套。**

### 5.5 抽奖：走回去才发现机器亮了

九槽满：**不弹窗、不传送**。人在别的房间时什么都不发生。回厅：机器已经亮（占位：机器热点上暖光 `.snappy` 闪 3 次后停住）。这是延迟的惊喜。

点机器：3 下闪 → 信从画布下沿进来（360–400ms）→ `.success` 一次。必中预置奖。再点只重读，无动画。

### 5.6 前院气氛：屋子在呼吸（不是第六次惊喜）

只发生在 `yard`。其它四景仍静帧。

**层级（后画的在上）：** 底图 → 天空字 → 云 → 左藤 → 右藤 → 热点。

**藤摇：** 每档左右各 3 帧透明图，对齐 320×160。帧间只动叶子尖 1–2px，茎几乎不动。循环 ping-pong。左右必须同一套时序，看起来像一阵风。

**长藤：** 档 0 / 1 / 2 是三套图，不是同一张调 opacity（opacity 会让疏的藤变成幽灵）。收下时立刻切档，摇的循环不要重置到第 0 帧（减动效除外）。

**云：** 一张（最多两张）窄条云，透明 PNG，按游戏像素步进，从一侧出、另一侧进。云必须能周期性让出填空，不能永远盖住 `____`。

**天空字：** 静止像素字，一行：`your ivy grows, ____`。字色用 palette 奶油/浅灰，不要系统 UILabel 风格。空白是四个下划线或等宽缺口，不要写成 `covered in you`。点天空：对话箱一句，不填空。

**减动效：** 藤档仍切；摇停在帧 0；云停在填空可见的 x。

## 6. 轻反馈（每下都有，但不抢惊喜）

| 事件 | 画面 | 触感 |
|------|------|------|
| 点中热区 | 1px 亮边，抬起消失 | `.light` |
| 走门 / 走楼梯 | 2pt 朝门方向再回正，然后切图 | `.light` |
| 废话 | 对话箱一句 | `.soft` |
| 点不中 | 无亮边 | 无，或极轻 `.soft` |
| 2 分钟仍在前院无 `ivy` | 门微闪 1px，每局一次；天空填空已在 | 无额外触感 |
| 进屋后 2 分钟零收集 | 闪厨房门缝或杯碗，每局一次 | 无 |
| 竖握 | 夜色 + 像素「横过来」。最多每 2s 偏 2px；减动效则静止 | 无 |

按下不要涟漪、不要整墙高亮、不要 hover 放大。

Intro：现成 `intro-ivy-1`…`4` 是 **160×240 竖图**，不能铺在横屏房间上。未补横屏片头前：已横则静态落前院，可 Skip；不要把旧竖图转 90 度播。Skip 无动画。

## 7. 触感（与玩法稿一致）

| 事件 | Feedback |
|------|----------|
| 换景 | `.light` |
| 废话 | `.soft` |
| 厅开/关灯 | `.medium` |
| 收下（槽亮的那一拍） | `.medium` |
| 大门对 / 其它短输入对 | `.success` |
| 大门非前缀 / 其它短输入错 | `.warning` |
| 拼字点中正确前缀 | `.light` |
| Reset 清空拼接行 | `.light` 一次 |
| 抽奖出信 | `.success` 一次 |

不要连震。动效和触感不要两套抢同一拍（收下：槽放大的同时 `.medium`）。

## 8. 代码与素材：现在就能做 / 后补 / 不做

工程现状：`PixelCanvas` 最近邻显示一张图；`ContentView` 点一下换房间名。没有热点、栏、特写、存档。换图本身是 0ms 切帧，符合「不要过场」。

物件画死在房间底图里。不要为收集状态复制整张 320×160（厅：灯 × 外套 × 海报 × 抽奖会组合爆炸）。世界变化只用 **透明补丁**。拼字关用独立底图 + 字盘板，不要把 16 块字烤进一张不可复用的 320×160。

### 8.1 无新图也能做

切景、厅开关灯、1px 亮边、触感、`ui-dialogue` 特写进出、`matchedGeometry` 色块占位、信箱系统键盘、槽用夜色/灯色方块、门/口袋代码闪、抽奖矩形暖光闪 3 下、压黑切灯/切门、拼字关用色块字盘 + 像素字拼接行。

### 8.2 后补（动效 API 不变）

| 优先 | 素材 | 用法 |
|------|------|--------|
| 1 | 前院底图（尽量少藤、无云、无天空字） | `yard` 换或新一张 `yard-base` |
| 1 | 天空字一张透明 320×160 | 静止；`your ivy grows, ____` |
| 1 | 云 overlay 1–2 张，宽可超过 320 | 步进循环 |
| 1 | 左藤、右藤各 3 档 × 3 摇帧（透明、对齐画布） | 共 18 张小 overlay；左右构图对称、疏密三档 |
| 1 | 九个 16×16 栏 icon | 替换色块；`.snappy` 不变 |
| 1 | 拼字关底图 320×160 | 门内侧 / 夜色石板；**不要**把答案写上去 |

## 9. 实现要点

```swift
// 房间底图：永远切帧
PixelCanvas(imageName: room)
    .transaction { $0.animation = nil }

// 用户点按才带动画
withAnimation(.smooth) {
    closeUp = .gelato
}

// 减动效
extension Animation {
    static func adaptive(_ animation: Animation, reduceMotion: Bool) -> Animation {
        reduceMotion ? .smooth(duration: 0.1) : animation
    }
}
```

状态用 `@Observable` 一处即可（已收 id、当前景、厅灯、大门是否已开、intro、已抽奖、**拼字行、字盘顺序、拼字关是否打开**）。不要上 Clinic 模块化、不要 `NavigationStack`。

热点矩形与 `PixelCanvas` **同一套 scale**，这样 1px 边和 `matchedGeometry` 才跟像素对齐。字盘板也走这套 scale，才能保证设备上 ≥ 44pt。
