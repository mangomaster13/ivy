# 物件与容器贴合规范

适用于凹槽、盒子、抽屉、托盘、桌面、床面和货架中的可交互物件。它细化 UI-RULES 的物理对齐要求，不改变已有谜题规则。依据：用户实测香水装盒时，瓶子虽在槽位范围内，却像浮在盒子上的贴图。

## 核心标准

**放置完成必须表现为一个可信的物理关系，而不是两个图片矩形重叠。** 玩家不依赖文字提示，就能区分空位、拿起、拖动与放妥。

## 1. 先定义关系，再设计素材

| 关系 | 必须成立的约束 |
| --- | --- |
| 站在桌面／货架上 | 支撑底面接触表面；瓶身可按透视高于桌面后沿；柜格另需满足侧面和顶部净空 |
| 平放在床面／托盘上 | 完整占地在承载面内；姿态与表面一致；布料等柔性物件按接触处形变 |
| 嵌入成型凹槽 | 物件姿态、主轴、肩部、底部与槽型相容；保留真实装配间隙和深度；边缘按实际深度遮挡 |
| 装入普通盒子／抽屉 | 物件由内部支撑，前壁按深度遮挡；不要求轮廓贴满整个容器 |

先指定 owning surface、放置姿态、相机、尺寸关系与接触位置。不要把“完整二维轮廓必须塞进桌面”误用于直立物件，也不要把“底部落地即可”误用于成型凹槽。

## 2. 容器和物件必须共同设计

- 先制作容器与物件组合后的批准稿，再拆分可交互素材。空槽与已放置态必须来自同一套几何关系。
- 相机高度、俯视角、可见顶面、主轴方向、光源和画风一致。库存图标可以采用方便识别的正面视角；入槽态需要时另做对应视角素材。
- 修正错误透视要重制对应素材；不能靠非等比拉伸、压扁、旋转正面图或强行裁切伪装。
- 成型槽按物件轮廓设计合理间隙，不要求像素级轮廓吻合。若谜题允许错放，槽型不能提前泄露顺序，也不能只让正确位置看起来贴合。

## 3. 按物理锚点定位

每组物件／容器在实现前记录以下放置契约，使用素材参考画布坐标，不使用猜测的屏幕百分比：

| 字段 | 要记录的内容 |
| --- | --- |
| 素材与视角 | 容器、物件、前景遮挡层、阴影的资源与批准稿 |
| 容器边界 | 内部可用轮廓、接触面、前沿、净空；凹槽另记主轴与关键轮廓点 |
| 物件边界 | 可见轮廓、透明留白、支撑／入槽锚点、方向和批准尺寸 |
| 变换 | 原图到 content 的统一缩放与偏移；背景裁切或留白如何映射 |
| 交互区域 | 点击范围、拖动抓取点、宽容落点区域与最终吸附姿态 |
| 状态 | 空位、已放、选中、拖动、交换、移除后的绘制和层级 |

直立瓶以可见底部支撑锚点定位；凹槽中的瓶以槽内姿态和对应锚点定位。图片框中心、透明 PNG 底边不是物理锚点。槽位身份固定，拿走物件后其他槽位不重排。

## 4. 深度由遮挡与接触共同表达

- 按真实关系组织容器后部／内底、接触阴影、物件、必要的前沿遮挡层。根据几何确定遮挡，不机械地给所有物件套前景边框。
- 接触阴影贴近支撑处，方向与软硬符合场景主光；凹槽保留内壁暗部。避免均匀外发光或悬浮卡片投影。
- 透明瓶的高光、玻璃明暗和环境色服从场景。加一道阴影不能修复错误的相机或姿态。
- 被拿走的物件不得继续烘焙在背景中。遮挡层负责表达真实前后关系，不能用来掩盖尺寸错误。

## 5. 操作前后保持同一个物件

- 拿起时解除必要遮挡与接触关系；拖动保留合理抓取偏移，不突然跳到手指中心。
- 放置成功后吸附到批准姿态，恢复对应遮挡与接触阴影。拖动与点击放置必须到达同一个最终状态。
- 无效落点返回来源位置，不能留下半嵌入状态；移动／交换后槽位、所有权和画面一致。
- 命中和落点由同一放置契约推导。落点可比可见槽宽容，最终位置仍必须准确；被遮挡的区域不能造成相邻物件抢点击。
- 状态反馈说明“已拿起／已放置”，不提前提示谜题答案是否正确。Reduce Motion 保留最终姿态与状态变化，减少移动动画。

## 6. 完成标准与证据

设计审查检查：相机一致 → 尺寸与姿态 → 锚点与间隙 → 接触与遮挡 → 光照材质 → 状态连续性。任何一项失败，都不能以“坐标在框内”或“构建通过”判定完成。

验收用例覆盖空容器、单件、全部放置、允许的错放、拿起、交换、移除与存档恢复，以及目标 content 尺寸。分别记录批准组合稿、源码放置契约、运行时画面和实际手势的检查范围，未检查项明确保留。

本规范不自动授权构建、设备启动或截图；运行时验证遵守 UI-RULES 的用户测试政策。新素材先按已有流程提交设计稿。规范落盘不等于现有场景已完成整改。


## 7. 任意组合采用可组合素材（香水制作台批准方案）

允许玩家自由组合物件时，生产空承载面、每种物件独立素材、必要前沿遮挡和接触关系；由状态组合画面。无需为所有排列生成整张照片，也不能把示意稿中的原料永久烘焙进工作台。只有改变相机、接触姿态或发生真实形态变化时，才增加对应变体。

先用宽扁物、高瓶、束状物、空位与不同组合确定承载范围；同一槽对所有允许物件都成立。物件身份、槽位身份与输入命中共享定义，拿走后保留真正空槽。代码复用不免除源素材透视与支撑检查；生产接入与用户实测分别记录。
