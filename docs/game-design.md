# Ivy — 游戏设计说明（iOS App 评审稿 · 横屏 · 五场景）

Date: 2026-09-17  
Product: 原生 iOS App（SwiftUI），礼物用 TestFlight 发给他  
Repo: 独立仓库（桌面 `ivy/`），与 Pocket 无关  
Pixel kit: `ios/Ivy/Assets.xcassets`（每景逻辑画布 **320×160**，最近邻放大）  
UX / 动效: [ux-motion.md](ux-motion.md)  
Audience: 作者评审  
Status: 大门锁改为 **拼字关**（点门进新画面，点选字母/数字拼接 `coveredinyou817`，对上自动进厅）。其它四景未改。

相对单房间稿：**玩法支柱、抽奖必中、普通石屋、不要两座城**不变。变的是空间：彩蛋按「这间屋该有什么」拆进至少五处，用点门/点楼梯换景，不是一张大厅塞满。

---

## 0. 一句话

**Ivy 是一个只装在他手机上的 16-bit 点选收集游戏：横过来走进一栋小石屋（前院、厅、厨房、楼梯、二楼），拇指近看物件，大门用点选字母拼出一句歌，私人物件进栏；收齐后回厅开一次抽奖，必中你准备好的奖。**

不是网站，不是开放大地图，不是锈湖全长，不是竖屏网页转 90 度。

## 1. 概念定义

### 1.1 三根支柱（动词，未改）

1. **近看** — 点家具进入特写。  
2. **收下** — 点收（大门则拼对那一行），栏里亮起 icon。  
3. **屋子记住** — 每收一颗，藤在整栋屋里多爬一点。

这个游戏是 **近看、收下、在小石屋里走动、看藤慢慢盖住各处**。

不做：战斗、合成、死亡、每日打卡、推送、桌面小组件、竖横双布局、地图 UI、屋里锁门、用钥匙开门、大门系统键盘 / 自由文本。大门用歌词开（见下），只这一把，动词是 **点选拼接**。

### 1.2 问题陈述

**焦点：** 人在杭州、工作忙、iPhone——这是 **谁在玩**。打开后横过来，进的是 **一栋普通小石屋**。可能躺着、可能切去回微信。

**可衡量的成功：**

- 装完第一次能在 **8–15 分钟** 收齐或安心退出（进度写在设备上，杀掉 App 还在，停在他离开的那一景）。  
- 九颗里至少四颗不靠你提示能认出（Vuori、gelato、烧鹅粉、两场电影）。  
- **不用地图也能走完五处**：每景出口 ≤ 2。**进厅必须先在大门拼字关上对上** `coveredinyou817`；对上之后屋里的门不再锁。  
- 横着拿时 Island / Home 不抢点。  
- **拼字关没有确认键**：点到对的那一串自动开门；点错不丢进度、不关在门外清空；可退格、可 **Reset 清空整行**、可回前院。  
- **整句副歌不上屏。** 前院夜空允许一行填空 `your ivy grows, ____`（空格是开门那半句，不是 817）。字盘不点亮「下一个正确字母」。打偏三次后口语提示仍不补全空格、不写出答案。  
- 竖着打开，**3 秒内能明白要转手机**。  
- 他觉得这是一盒卡带，不是 H5。

**表达：** 锈湖式点景 + 普通石屋的房间分工；触感是循环里的直接反馈。转手机 = 把卡带推进去。

### 1.3 80/20

80% 时间：在某一景里点物件。  
20%：intro、转屏、走门、大门拼字、抽奖。  

走门必须是 **点一下切 320×160 图**，不要走路条、不要过场。五张背景是换空间换来的成本；第六间、地图、**第二把锁**都算膨胀。

**唯一的锁是前院大门。** 点门 → 切进拼字画面 → 按顺序点字母/数字，系统帮他拼在一行上 → 拼出 `coveredinyou817` 自动进厅，同时收下 `ivy`。不要藤上再验一次。对过之后，大门只是普通门，进出不再问。屋里厨房/楼梯门始终开着。

不要系统键盘、不要自由文本、不要确认键。这是记忆型关卡（会那一句），不是打字技能关。

前院是 **活的夜**：藤随风切帧摇、云平移露填空。这是气氛，不是第六间，也不另加一把锁。

### 1.4 约束三角

要 **好**（横屏手感、屋子像屋子）和 **范围小**。五景封顶。速度靠：同画布规格、锁横屏、TestFlight。

**不选：** 竖横双布局；旋转旧竖图；WKWebView；一景塞满九个彩蛋；大门 QWERTY（Hick：一屏选项过多）。

工程在 `ios/`。每景 320×160 **新画**。拼字关与房间共用同一套画布规格。

## 3. 主题

**一栋小石屋被藤慢慢覆盖 —— 屋子很普通，私货写在该在的房间里。**

游戏空间就是这一栋，不是两座城。窗就是窗。地名若出现，只在 **物件** 上（箱子、房卡），不当房间名。

环境叙事靠房间分工（私人空间原则）：厨房有吃的，厅有外套和海报，卧室有床和箱子，楼梯上会掉东西，前院有石墙和藤。**大门认歌**：会那一句才能进，像屋子认得他。认的方式不是填表，是把一句歌点到门板上。整句副歌不上屏；前院天空用填空把人推向那半句，数字日子仍靠记忆，不写在云上，也不在字盘上点亮。

iOS 载体：图标和启动仍是这座石屋。不要 SF Symbols 做主界面。

## 4. 核心循环

```
在某一景里点
    → 废话  或  特写收下  或  拼字关（仅未开的大门）  或  点灯
        → 栏亮 + 这栋屋的藤多一点
            → 还想点这间的角落，或点门走进下一处
```

换景不是新动词，是「点」门洞。循环在每一景都要单独成立：厨房只点碗也要有趣。

**大门是第一道关，也是 `ivy` 这一颗。** 点前院的门切进拼字画面；拼对才进厅，藤进栏。点藤不另开拼字——藤只给口语提示（面包屑），避免同一句歌验两次。

**前院两侧长藤：** 可收集的仍是两颗（左 `sep29`、门上的 `ivy`），不新增第十颗。每收下其中一颗，**左墙和右树/右墙同时**长一档，不是只长在彩蛋那一侧。

**天空填空**不是第三玩法：云在字前面飘，空白处露出 `your ivy grows, ____`。点天空仍是废话/读空，不进拼字关。

**关灯**仍不是第三玩法：只发生在 **厅**，只照亮厅里的外套手机。不要做成「全屋总闸」。

**动词：**

| 动词 | iOS 操作 | 成功 | 失败 |
|------|----------|------|------|
| 点 | 特写 → 收下 | 进栏 | 废话只说话 |
| 点门 / 点楼梯 | 屋里：当场切景。前院大门：未对歌词则切进拼字画面，对过则切厅 | 到了 / 进厅并收下 ivy | 拼错：字还在板上，留在关内或退回前院 |
| 点灯 | 仅厅里，当场亮/灭 | 厅换光；灭时口袋亮屏 | 无失败 |
| 拼字（仅大门） | 点字盘字母/数字；系统拼接；对上自动开 | 当前串恰好是 `coveredinyou817` | 不是前缀：口语提示；不扣进度；不对不进屋 |
| 短输入（信箱 / Vuori） | 数字或英文键盘 | 规范化匹配 | 提示；不扣进度 |

无合成、无拖拽、无限时。屋里的门不锁。只有大门这一把。无自由文本开大门。

### 4.1 大门拼字关（完整规则）

分类：**记忆型**（会不会那一句），不是打字技能、不是找不同、不是解密运算。随机的是 **字盘位置**，不是答案。答案一经生成就是确定的：同一串点击永远得到同一行字；只有恰好 `coveredinyou817` 才开门（谜题确定性）。

**为什么不用键盘：** 横屏礼物、可能躺着玩；系统键盘会盖住确认、露出工具 App 气质，把「屋子认他」做成填表。Hick：36 键决策过载。改成最多 16 块板，目标是回忆歌词顺序，不是瞄准 QWERTY。

**进关：** 前院、大门未开、点门热点 → **切到一张新的 320×160 画面**（门的内侧 / 夜色字盘），不是前院压暗 + 输入框。栏收起。前院的云和藤在这张画面里不出现。

**画面结构（同一套壳，不是 sheet）：**

```
ZStack
  Color("Night")
  320×160 拼字画布
    上行：拼接行（stave）——他已经点出的字，像素字体，奶油色
    中下：4×4 字盘（16 块字母/数字板）
    左：离开 `ui-back`（回前院，字保留）
    拼接行：`lock-mark-*` 奶油字，接在铁槽里
    拼接行右侧：`ui-del` + `ui-reset`
    中下：4×4 `lock-tile-*` 石板（a c d e i n o r s u v y 1 7 8 9）
    底图：`lock-bg`（不含字母）
```

没有确认、没有空格键、没有系统键盘、没有 15 个空槽（会泄露长度）、没有「下一个正确字母」高亮。

**字盘生成：**

| 项 | 规则 |
|----|------|
| 标准答案 | `coveredinyou817`（15 个字符，全小写，无空格） |
| 必出（去重） | `c d e i n o r u v y 8 1 7`（13） |
| 诱饵（固定 3 个） | `9`（信箱日期陷阱）、`a`、`s`（旧别名残留，现已不算对） |
| 布局 | 16 块洗乱，每次 **打开** 这张画面时重洗 |
| 打开期间 | 位置冻结（切去微信再回来也不重洗，避免点错） |
| 复用 | 板不消耗。`o`、`e` 在答案里出现两次，点两次同一块 |
| 不做 | 全字母表、标点、`0`、`.`、空格；不保证「下一正确字」总在某 6 块里（那会变成猜亮块） |

**拼接（系统替他拼）：**

1. 点一块板 → 该字形立刻接到拼接行末尾。  
2. 若当前串 **恰好** 等于 `coveredinyou817` → **自动开门**（无确认）。`.success` → 短黑 → 切厅 → 收下 `ivy`。  
3. 若当前串是答案的 **前缀**（例如 `cov`）→ 轻触感，继续。不要庆祝，不要亮下一字母。  
4. 若当前串 **不是** 前缀（点了 `9`、点乱了顺序）→ `.warning`，末字抖 2pt，口语提示升级；字留在行上，等他退格或 Reset。  
5. 行长到 20 仍未对上 → 拒绝再接，必须退格或 Reset。  
6. **退格**：删最后一个字，不增加失败次数。点错一块时用。  
7. **Reset**：清空整行，留在拼字画面。字盘 **不重洗**。不增加失败次数。拼乱一整串时用，避免连点十五次退格。行已空则无操作、无触感。  
8. **离开**：回前院，大门仍锁；拼接行写入存档，下次开门还在。字盘下次打开再洗。Reset 不离开、不存空行以外的副作用。  

**不算对（也不再收别名）：**

- 只拼 `ivy`、只拼 `817`、只拼 `coveredinyou`（缺日子）。  
- `imcoveredinyou` / `iamcoveredinyou` / 空格 / `8.17` / `0817` / 把 `929` 拼进去。  
- 字盘没有空格和点，系统也不插入空格。

**面包屑（渐进提示，不泄答案）：**

| 来源 | 给什么 | 不给什么 |
|------|--------|----------|
| 天空 | `your ivy grows, ____` | 副歌、`817` |
| 两侧藤 | 口语，三次后提到人和八月的一天 | 整句、数字 |
| 拼错三次 | 加强口语（仍不补空格） | 闪红屏、点亮正确板 |
| 拼进 `9` | 那日子在信箱上，门要另一个 | 直接写出 817 |

心流：入门靠天空填空把人推向「有一句」；练习是在字盘上找回顺序；对上的美学奖励是屋子认他（短黑进厅），不是「Password correct」。

**信箱 `sep29`、厅 `vuori`：** 仍是短输入（数字 / 英文键盘），不是这套 16 盘。不要把全游戏做成拼字。大门是唯一的「密码关」。

## 5. 体验结构与节奏

**小沙盒屋子 + 一道大门 + 线性收尾。** 进厅之前，前院可自由点石牌和藤；厅、厨房、楼梯、二楼要先对上歌词。九个里除 `ivy` 外不锁顺序；九槽满后厅里抽奖机亮，要自己走回去开。

```
        [前院]  ← 大门：先对歌词（ivy）
           │ 对过之后只是普通门
        [ 厅 ]──门──[厨房]
           │ 楼梯口
        [楼梯]
           │ 往上
        [二楼卧室]
```

| 时间 | 段落 |
|------|------|
| 0:00 | 竖握：转屏提示。已横：启动画面这座屋。 |
| 0:00–0:20 | Intro 藤爬外墙，可 Skip。结束后落在 **前院**。 |
| 0:20–2:00 | 前院：活的夜、天空填空、左侧信箱、点门进拼字关。拼出 `coveredinyou817` 才进厅。 |
| 2:00–8:00 | 厨房入门点（gelato / 碗）、厅海报、关灯找手机、楼梯、二楼。 |
| 最后 | 走回厅，抽奖机亮。 |

约每换一景就是一次「新东西」（7 分钟注意力里足够换景）。整局仍 8–15 分钟，不靠加第六间拉长。

2 分钟仍在前院没收 ivy：门轻微闪；天空填空已在；点藤给更口语的提示，仍不补全空格。不要系统 Alert。已进屋后的 2 分钟零收集：闪厨房门缝或杯碗。厅灯已灭仍没收 Vuori：口袋脉动。

切去微信：停在原景 + 原特写 / 拼字关 / 短输入；拼字行与字盘位置都还在；信箱键盘可丢，数字保留。不要重播片头。

## 6. 场景设计

所有可玩景同一套壳：画布 **320×160**，安全区内居中，左右 `night` 信箱，最近邻。物品栏九槽贴在 Home 指示条上方，与画布 4–8 pt 死区。锁横屏左右。无 Tab、无地图、无系统导航栏。

出口画在图里：门洞、楼梯段。每景 **可走出口 ≤ 2**（Hick）。热区 ≥ 44 pt。不用边缘返回。特写才允许下滑关。拼字关不是特写：下滑不关（避免躺着误关），只能点离开、Reset 后继续、或拼对。

### 6.1 启动与转屏

已横：静态石屋一帧。竖握：夜色 + 像素「横过来」，转到横再进。不是把画面侧着播。

### 6.2 Intro

全屏夜色。屋在黄金分割附近。点伸手或点屋：藤爬外墙四帧。SKIP 在安全区内上侧，44 pt。首次走 intro，之后进 **前院**。收齐后抽奖信角落可「再看片头」。

### 6.3 五处可玩景

固定机位，点矩形热点。每景只放 **这个房间会有的东西**。

#### 前院 `yard`

石屋正面、夜、门在中轴。**彩蛋分列左右**：左是信箱 `sep29`；右不新增第十颗，右侧重的是对称的藤。门仍是唯一的锁，收下 `ivy`。

夜空有云，云下空白露出像素字 `your ivy grows, ____`。墙上的藤会摇；每收前院一颗，左右两侧藤同时密一档。

| 可点 | 作用 |
|------|------|
| 门 | **未对歌词：** 切进拼字画面（新图，不是键盘）。拼出 `coveredinyou817` → 进厅 + 收下 `ivy`，大门此后不再问，左右藤同时 +1 档。**已对过：** 直接进厅。门缝漏暖光，但未开门前过不去。 |
| 左藤 / 右藤 | 废话 + 口语面包屑。**不**再开拼字，避免验两次。 |
| 左侧信箱 | 彩蛋 `sep29`（数字键盘）。关在门外也能收；收下后左右藤同时 +1 档。 |
| 夜空 / 云 | 废话；可点到字，但不填空、不弹键盘。 |
| 石头 / 路径 | 废话 |

藤密度（仅前院两侧 overlay，三档）：

| 前院已收 | 档 |
|----------|----|
| 0（`sep29` 和 `ivy` 都无） | 疏：底图上原有的一缕 + 轻摇 |
| 1 | 中：左右同时明显爬上墙/树 |
| 2 | 密：两侧都更厚，仍能看见门 |

无抽奖机、无床、无碗。不在前院加第三颗彩蛋。

#### 厅 `hall`

后墙、海报、挂钩上的外套、落地灯、角落灰掉的抽奖机。左或右一道门进厨房，一道楼梯口。

| 可点 | 作用 |
|------|------|
| 门（回前院） | 回前院（不重新问歌词） |
| 门（厨房） | 进厨房 |
| 楼梯口 | 进楼梯 |
| 海报 | 彩蛋 `cinema`（色块剪影；点进去才是 Fall 2 / Hope 双票） |
| 外套/手机 | 彩蛋 `vuori`（灯灭时口袋亮屏） |
| 灯 | 只切换 **这一景** 的亮灭 |
| 抽奖机 | 九槽满才可点 |
| 窗、梁 | 废话 |

**灯亮/灭只作用于厅。** 规则同前：默认亮；灭时仅 Vuori 亮屏；不锁其他彩蛋；收走后不再亮；只做厅的暗调色 + 口袋 overlay；状态存档。

#### 厨房 `kitchen`

灶台、碗、杯子。一道门回厅。

| 可点 | 作用 |
|------|------|
| 门 | 回厅 |
| gelato 杯 | 彩蛋 `gelato` |

### 6.4 特写（各景共用）

全屏层，左右分栏，图 : 文 ≈ φ。返回在文栏下沿 44 pt。下滑可关。8.17、双票（**Fall 2** / **Hope**）、嫌弃口味只出现在对应特写。

### 6.5 大门拼字关 + 其它短输入

**大门（`ivy`）** 用 §4.1 的独立画面，不走这套键盘板。

**信箱 / Vuori** 仍是短输入：当前景压暗，栏收起。输入框与确认同一行，贴在键盘上沿。数字题用面板确认。点空白不收键盘。取消在板左端 44 pt。

不要把大门做成「压暗前院 + TextField」。不要给拼字关加确认。

### 6.6 抽奖

九槽满 → **厅**里机身亮。人若在别的房间，不弹窗传送；回厅才能看见亮了（weenie：记得那台灰机器）。点了必中预置奖。再点只重读。信全宽，照片在 `frame-photo` 里，人脸不像素化。第一版双击放大。

## 9. 反馈与容错

触感表如下。过渡时长、五次惊喜、减动效和实现约束见 [ux-motion.md](ux-motion.md)。不要用教学 Alert，不要把换房做成过场。

| 事件 | 反馈 |
|------|------|
| 换景 | `.light`；无加载条 |
| 废话 | `.soft` |
| 厅开/关灯 | `.medium` + 厅立刻换光 |
| 收下 | `.medium` + 栏 + 藤 |
| 进大门对/错 | `.success` 进厅 / `.warning` 留在拼字行上 |
| 其他短输入对/错 | `.success` / `.warning` |
| 抽奖 | `.success` 一次 |
| 杀进程 | 存：已收 id、intro、已抽奖、灯、当前景、**大门是否已开**、拼字行、拼字关是否打开 |

| 错误 | 回应 |
|------|------|
| 歌词卡住进不了门 | 前院仍可点信箱、两侧藤、看天空填空；拼字行可退格或 Reset；三次打偏加强口语；离开后门仍锁、字还在；不关拼字清进度 |
| 点错字盘（运动误差） | 退格 44pt，贴在拼接行旁（Fitts：常用控件靠近正在看的行） |
| 拼乱一整串（错误行动） | **Reset** 清空整行，留在关内；字盘不重洗。不要自动清空、不要踢回前院 |
| 把 929 拼进门 | 诱饵 `9` 在盘上；口语：日子在信箱；不自动删 |
| 藤和门都要验歌 | 只验门；藤只提示 |
| 等确认键 | 没有确认；拼对即开 |
| 找不到屋里下一间 | 门洞漏光、楼梯只有一条路 |
| 关厅灯以为全屋坏了 | 厨房/卧室仍亮；只有厅变暗 |
| 九槽满以为没了 | 不弹窗；厅机器亮，靠他走回去 |
| 点窗当门 | 废话一句；门热区更大、更亮 |
| 边缘滑退出 | 景内禁用边缘返回 |
