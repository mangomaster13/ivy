# Noodles · 找菜单与点菜设计

2026-09-24。玩法与视觉已获用户批准；本轮接入代码及独立生产素材，尚未运行构建或设备验收。当前工作分支 main；保留已有未提交改动。

## 关卡节奏

找菜单承担主谜题；点菜承接真实回忆。保留 Big Top 入口与餐馆两视角、原来五样餐食、noodle 收藏和十三个收藏槽。取消描图纸旋转平移、八柜格逐个尝试和四页分类菜单。

服务台左侧的短铅笔与右侧的小检修镜直接可见、分别拿取。工具进入 Tools，但不自动选用。柜台交班簿上页撕去，剩下压痕；台面后挡板的窄观察口可见刻痕，但无法直接读全。两件工具可按任意顺序使用。

1. 选铅笔涂显交班簿：一次短笔画完成有意的显影，不考覆盖率；无障碍提供等价操作。显影后保持可读，原图进入 Notes。
2. 选检修镜放入观察口：自动落在真实支撑槽中，显示固定镜像，不增加对准角度小游戏。镜像原样进入 Notes，不自动翻正。
3. 结合图案分布与镜中路线，设置四轮图案锁；拉动实体把手整组判定。错误不泄露正确位置，保留四轮输入。
4. 开抽屉后另点菜单拿取。回餐桌将菜单放到已有夹板，直接打开可勾选内容。
5. 十项混排菜单勾选五项，铜铃提交；错误保留选择，只提供整单反馈。成功上菜并开出口；点餐食进入 Element 并保存 noodle。

## 唯一解与镜像契约

两份证据共享同一个两行四列柜格示意图。以下 A/B 和列号仅为设计坐标，玩家画面不印这些编号。

| 正面坐标 | 1 | 2 | 3 | 4 |
| --- | --- | --- | --- | --- |
| A 上排 | 碗 | 茶杯 | 鱼 | 汤匙 |
| B 下排 | 叶 | 鹅 | 筷子 | 茶壶 |

交班簿仅呈现完整图案分布，不含路线。正面示意图左上有三角缺角，右下有一对螺钉。

背板雕刻为从柜子正面坐标定义的 A1 → B2 → B4 → A3。路线起点为小圆环，终点为箭头，途中无分叉。背板不含器物图案。实际镜中画面必须由这份几何整体左右翻转得到，不能独立重画：镜中路线为 A4 → B3 → B1 → A2，缺角在右上、双螺钉在左下。

玩家凭缺角与螺钉恢复方向，从交班簿取图案；唯一答案为 碗 → 鹅 → 茶壶 → 鱼。八种图案同一套轮廓，在纸、锁轮和 Notes 上身份一致。碗无把手、茶杯单柄、茶壶有壶嘴与盖；鹅用长颈侧影，鱼为横向带尾轮廓，避免小尺寸误认。

四轮均支持八种图案，允许重复；没有读过证据的强制门槛，也没有正确前缀反馈。盲扫最坏 4096 次整组拉柄，并非点八个柜门就能完成。这个数量仅说明无低成本盲扫；真正的谜题依据是镜像坐标映射与两证据取值，而非单纯增大密码空间。不加次数惩罚或时间限制。

## 十项菜单

稳定菜品身份沿用现有目录：Half Roast Goose、Quarter Roast Goose、Steamed Rice、Rice Noodles、Egg Fried Rice、Wonton Noodles、Lemon Tea、Ovaltine、Milk Tea、Lemon Water。正确集合仍为 Half Roast Goose / Steamed Rice / Rice Noodles / Lemon Tea / Ovaltine。

首次创建新版菜单时打乱十个稳定 ID 并持久保存；选择保存 ID，不能保存显示位置。切景、打开 Notes、退出和重启不重新洗牌。设计图中的顺序仅为一份示例，全部未选中；不以颜色、分组或装饰泄露五项答案。

布局采用同一张横向折页菜单上的三列 4/3/3 项，无类别标题、无页码、无多页翻动。菜名作为独立透明题字素材，配合纸面坐标放置，避免把固定排序烘焙在底图中。全部十项同时可见，铜铃独立放在菜单右边桌面上。

生产版重新构图为 12:5 横向纸面，三列 4/3/3 项；内容预算至少 588 × 245 pt（不含 gutter/footer），四行至少 48 pt，菜名独立 Juniper 素材可换行。纸面 x=1%…82%，文字列中心 x=14% / 39.5% / 65%，行区起点 y=11%，铜铃中心 x=91.5%、y=56%。使用同一 aspect-fit 变换，不拉伸家具、不滚动、不切页。小于该预算的 viewport 不在本轮设计支持范围，尚未做设备验收。
